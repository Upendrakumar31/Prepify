# Prepify

AI-powered interview preparation platform that analyzes your resume, job description, and self-description to generate a personalized interview preparation plan.

## Live Demo

🚀 Live Application: https://prepify-resume.onrender.com

📂 GitHub Repository: https://github.com/Upendrakumar31/Prepify

## Features

- Resume analysis
- Job description analysis
- AI-powered interview preparation
- Technical and behavioral questions
- Skill gap identification
- Personalized preparation roadmap
- ATS-friendly resume PDF generation
- JWT-based authentication
- MongoDB database integration

## Tech Stack

### Frontend
- React
- SCSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT

### AI & Tools
- Google Gemini API
- Zod
- Puppeteer

## How It Works

1. Upload your resume.
2. Enter the job description.
3. Provide a short self-description.
4. Prepify analyzes the provided information using Gemini AI.
5. The platform generates a personalized interview preparation plan.
